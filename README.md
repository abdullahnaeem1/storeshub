# StoresHub

A modern, responsive commerce-platform landing page built with Next.js, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000.

## Available commands

- `npm.cmd run dev` — start the development server
- `npm.cmd run build` — create and validate a production build
- `npm.cmd run start` — serve a production build

## Project structure

- `src/app/page.js` — page content and sections
- `src/app/components/` — navigation, contact dialog, and animation helpers
- `src/app/globals.css` — global styling and responsive rules
- `public/feature-1.png`, `public/feature-2.png` — feature-section visuals

## Notes

The contact form currently displays an in-page success state. Connect it to an email provider, CRM, or server action before using it to collect real enquiries.
